# AI user-agent tokens for signal S1 ("declares an AI user agent").
# Frozen with PREREGISTRATION.md. Drafted 16 October 2026; revised 19 October 2026 for version 2
# of the pre-registration (Anthropic's list added; see its section 0).
#
# Matching: a session's User-Agent matches a row if it contains the token, ignoring case.
# Columns (tab-separated): token, operator, kind, vendor IP list used for S2, source.
#
# kind:
#   training     - collects pages to train models          -> H4 candidate if verified (S2/S4)
#   search_index - collects pages for an AI search index    -> H4 candidate if verified
#   user_fetch   - fetches a page because a person asked    -> H5 candidate
#   user_agent   - an AI agent acting for a person          -> H5 candidate
#   other_use    - AI company tool that does not collect pages (e.g. ad checks) -> H3
#
# Sources (all opened 16 October 2026):
#   CF   = Cloudflare AI Crawl Control bot reference, updated 23 Apr 2026
#          https://developers.cloudflare.com/ai-crawl-control/reference/bots/
#   OAI  = OpenAI, Overview of OpenAI crawlers  https://developers.openai.com/api/docs/bots
#   META = Meta, Web crawlers  https://developers.facebook.com/docs/sharing/webmasters/web-crawlers
#   GA   = PPC Land on Google-Agent (added to Google's fetcher list 20 Mar 2026)
#          https://ppc.land/google-agent-joins-the-crawler-list-as-ai-browsing-gets-an-official-identity/
#   OTT  = Otterly AI crawlers reference guide, 22 Jan 2026  https://help.otterly.ai/ai-crawlers
#   PPC  = PPC Land, user-agent strings article, 28 Jun 2026
#   ANT  = Anthropic's crawler IP list, https://claude.com/crawling/bots.json (opened 19 Oct 2026;
#          the file's creationTime is 2026-08-18). One list for all of Anthropic's agents: it does
#          not separate crawling from on-request fetching
#
# NOT on this list, on purpose:
#   - ChatGPT agent mode and other browser-based agents send an ordinary Chrome user agent.
#     They are caught (if at all) by S4: a Signature-Agent header (ChatGPT agent signs requests
#     per Cloudflare, Aug 2025; Google is testing the identity https://agent.bot.goog).
#   - Robots.txt-only tokens that are never sent as a user agent: Google-Extended,
#     Applebot-Extended.
#   - Gemini-Deep-Research: its user agent "varies" (OTT); not matchable by token.
#
